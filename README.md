# primitive_db

Примитивная консольная база данных для управления таблицами. Проект реализован на Python 3.12 с использованием менеджера пакетов `uv`.

## Описание

`primitive_db` — это CLI-приложение, позволяющее создавать, просматривать и удалять таблицы через интерактивный командный интерфейс. Метаданные хранятся в JSON-файле `db_meta.json`.

### Синтаксис команд

`create_table <имя> <столбец:тип> ...` - Создать таблицу
`list_tables` - Показать все таблицы
`drop_table <имя>` - Удалить таблицу
`help` - Справочная информация
`exit` - Выход из программы

### Поддерживаемые типы

- `int` — целое число
- `str` — строка
- `bool` — булево значение

> Столбец `ID:int` добавляется автоматически **всегда** и становится
> первым столбцом таблицы. Указывать его вручную не требуется.
