# primitive_db

Примитивная консольная база данных для управления таблицами. Проект реализован на Python 3.12 с использованием менеджера пакетов `uv`.

## Описание

`primitive_db` — это CLI-приложение, позволяющее создавать, просматривать и удалять таблицы через интерактивный командный интерфейс. Метаданные хранятся в JSON-файле `db_meta.json`, каждой таблице создается отдульный файл в каталоге `data/{table_name}.json`

### Возможности

- Создание и удаление таблиц
- Полный набор CRUD-операций: `insert`, `select`, `update`, `delete`
- Просмотр информации о таблице (`info`)
- Валидация типов данных (`int`, `str`, `bool`)
- Красивый табличный вывод результатов через `PrettyTable`
- Сохранение состояния между сеансами работы
- Интуитивный командный интерфейс с обработкой ошибок

### Поддерживаемые типы

- `int` — целое число
- `str` — строка
- `bool` — булево значение


> Столбец `ID:int` добавляется автоматически **всегда** и становится
> первым столбцом таблицы. Указывать его вручную не требуется.

## Справочник команд

### Управление таблицами

| `create_table <имя> <столбец1:тип> ...` | Создать новую таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя>` | Удалить таблицу вместе с данными |

### CRUD-операции

| `insert into <имя> <значение1> <значение2> ...` | Добавить запись (без `ID`) |
| `select from <имя> [where <условие>]` | Выбрать записи |
| `update <имя> set <присваивание> where <условие>` | Обновить записи |
| `delete from <имя> where <условие>` | Удалить записи |

### Системные команды

| Команда | Описание |
|---------|----------|
| `help` | Справочная информация |
| `exit` | Выход из программы |

## 💡 Примеры использования

### 1. Запуск и создание таблицы

```text
>>> database

Первая попытка запустить проект!

***
<command> exit - выйти из программы
<command> help - справочная информация

Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

### 2. Вставка данных (INSERT)

```text
Введите команду: insert users 'Alex' 28 true
Запись успешно добавлена в таблицу "users".

Введите команду: insert users 'Liza' 35 false
Запись успешно добавлена в таблицу "users".
```

### 3. Выборка данных (SELECT)

```text
Введите команду: select from users
+----+-------+-----+-----------+
| ID | name  | age | check     |
+----+-------+-----+-----------+
| 1  | Alex  | 28  | True      |
| 2  | Liza  | 35  | False     |
+----+-------+-----+-----------+

Введите команду: select from users where age = 28
+----+-------+-----+-----------+
| ID | name  | age | check     |
+----+-------+-----+-----------+
| 1  | Liza  | 28  | True      |
+----+-------+-----+-----------+
```

### 4. Обновление данных (UPDATE)

```text
Введите команду: update users set age = 29 where name = 'Liza'
Обновлено записей: 1.
```

### 5. Удаление данных (DELETE)

```text
Введите команду: delete from users where name = 'Alex'
Удалено записей: 1.
```

### 6. Информация о таблице (INFO)

```text
Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 1
```

### 7. Удаление таблицы

```text
Введите команду: drop_table users
Таблица "users" успешно удалена.
```

## Правила написания условий

### Формат значений

Строка  `name = 'Liza'` (обязательно в кавычках)
Число  `age = 28` (без кавычек)
Булево  `check = true` или `check = false`

Можно указывать несколько условий через запятую:

```
select from users where age = 28, is_active = true
```
